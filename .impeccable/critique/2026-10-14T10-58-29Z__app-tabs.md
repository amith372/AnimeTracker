# Questions to Consider

1. If the dual rollup is the only reason this app exists, why is it never drawn? What would a two-track meter per Library row look like, with WONT_WATCH hatched rather than silently counted?
2. Reconcile is modeled as a confirmation step but is really a multi-session data-correction job — what changes if it becomes a persisted, resumable, searchable queue that lives permanently in the app?
3. Who is the empty Library actually for? Every guest and email signup meets the product as "Nothing here yet."
4. Is userInterfaceStyle "light" deliberate? If not, one string is the highest-leverage change here. If so, a complete dark theme is dead code on native while web shows it at 2.54:1.
5. DESIGN.md claims AA where the figure is 3.80:1. Is accessibility out of scope, or was it believed handled? Only one of those is a five-token fix.
